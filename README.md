# QPass Thesis Documents

This repository contains the complete updated thesis project information for:

**QPass: A QR-Based Context-Aware Student Safety Monitoring and Emergency Alert System Using a Progressive Web Application**

Open `QPass_Updated_Thesis_Project_Information.md` to view the complete document. It is formatted in Markdown and can be opened directly in GitHub or copied into Microsoft Word and saved as a `.docx` file.

The document includes the project overview, objectives, workflows, QR-code and geofencing design, Emergency Mode, SOS and Mark as Safe features, privacy and security requirements, PWA requirements, database entities, scope, limitations, research contribution, use cases, evaluation criteria, final system description, and abstract.

A DOCX-generation agent was unavailable during this request, so the source document is provided in a clean, Word-compatible Markdown format rather than as a binary `.docx` attachment.
